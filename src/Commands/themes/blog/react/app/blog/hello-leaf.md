Every file in `app/blog` becomes a post. The frontmatter block at the top sets the title, date and description; everything below it is markdown.

## Writing a post

Create `app/blog/my-post.md`, give it a frontmatter block like this one, and it appears at `/blog/my-post`. That's the whole workflow: no database, no admin panel, just files you commit with your code.

Happy writing!
